## Access

买家身份仅从服务端会话读取。订单列表在分页前筛选本人订单，详情在读取仓储前验证归属。客服根据现有角色访问独立接口，可按买家账号和订单号组合筛选。订单归属沿用现有演示账号规则。

买家通过 `order_id` 搜索完整编号或前缀，通过 `receipt` 筛选签收状态。店铺订单和 Olist 样本都在分页前匹配，延迟签收归入已签收，运输中和超期未签收归入未签收。订单列表 URL 保留筛选条件，供详情、返回和分页复用。

## Data

订单号游标支持跨两种来源分页。店铺订单展示现有签收和退货条款。Olist 详情展示已有日期和商品行，沿用 Decimal 金额累计和 BRL 标注，并提示缺少明细。

## Navigation

买家登录进入订单目录。订单详情使用单独 URL，可以刷新或复制给同一账号使用。从详情进入售后时，把明确订单号交给既有对话。客服订单详情可跳到该单的工单筛选，工单上的订单号也可打开详情。
