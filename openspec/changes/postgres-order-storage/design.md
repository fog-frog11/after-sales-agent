## Context

订单读取目前使用内存样本。Agent 用已验证的订单号调用 Python 售后判断。

## Goals / Non-Goals

- 给订单增加持久化数据源，使用参数化 SQL 查询。
- 从 `/api/config` 显示订单数据源，与模型模式分别展示。
- 本阶段只处理订单表和样本，退货期限仍由页面选择。

## Decisions

- 将订单查询函数作为依赖传给售后规则。配置数据库 URL 时使用 PostgreSQL，未配置时使用现有演示数据。
- 每次查单通过短生命周期连接读取一行。连接设定有限的连接和查询超时。
- 初始化 SQL 在一个事务内创建订单表和插入样本。主键冲突时保留已有记录。
- 数据库异常返回 HTTP 503，前端显示可读错误。响应中隐藏连接详情。

## Risks / Trade-offs

- [数据库不可用] → 配置 PostgreSQL 后明确报错，防止界面展示与真实来源不符的结果。
- [重跑初始化覆盖更新] → 使用主键约束和冲突时跳过插入。
