## Context

项目的真实服务已经接通订单库、会话检查点、政策索引、DeepSeek 和 MCP。

## Goals / Non-Goals

- 用固定输入和预期业务事实覆盖关键链路。
- 分项报告失败原因和用时，允许后续用例继续。
- 使用本机演示数据和一张已提交的工单。

## Decisions

- 通过 HTTP 调用运行中的工作台。启动前核对配置中启用的能力。
- 对模型输出核对状态、条款编号和原文主题。措辞允许变化。
- 重复确认用例读取既有演示工单的确认 ID，并验证两次确认都指向原工单。
- 在项目 .local 下写入带时间戳的报告。任一用例失败以非零状态退出。

## Risks / Trade-offs

- [外部模型或服务暂不可用] → 保留分项失败信息，评测不重试模型请求。
- [模拟订单数据已改动] → 根据报告核对实际结果与固定预期。
