## 订单明细和金额

- 用 `order_id` 匹配本机已导入的 Olist 订单，用 `product_id` 关联商品品类。库里每行保留源明细序号、商品编号、原始品类、商品价格和运费。同一订单内相同商品的多行明细分别计数。
- 预览只读取现有样本订单编号。指定 `--apply` 后在同一事务内写入明细，以订单源编号和明细序号去重。找不到明细的订单继续保留物流记录。
- 订单明细用数据库记录计算。所有金额用十进制表示，以巴西雷亚尔为单位。合计只包含数据集记录的商品金额与运费。
- API 使用现有会话和订单归属检查，归属匹配后才调用仓储。没有明细时返回明确状态。Web 页面切换订单时清空商品结果并忽略迟到响应。
