## Context

工作台通过订单店铺筛选 Milvus 条款，使用 BM25 取三条证据，并交给模型组织带引用的回答。现有两家演示店的短条款适合检查店铺隔离和工作流。

## Decisions

- 使用 Sierra Research 的公开零售文档，按原文标题切分。查询来自公开任务的原始来电原因，评分目标通过公开动作映射到章节。
- 实验集合使用与语料语言匹配的英语标准分析器，以内容哈希命名。ShopTC 段落只加入扩容实验的检索池，使用固定种子抽样并记录来源。
- 同时报告至少一条命中、按题平均召回、全部目标命中及请求错误。并发测试测量最大的实验检索池的延迟和吞吐。

## Risks / Trade-offs

- 执行动作只覆盖部分条款依据，评测报告保留动作映射和逐题结果供复查。
- 跨网站干扰语料用于暴露相似文本排序问题。实际工作台先用订单店铺隔离语料。
- 英语检索与中文问答分别验证。模型生成、业务判断和引用仍由工作台 API 测试检查。
