## Context

现有 Python 函数已实现模拟订单查询和日期比较。第一版服务于个人学习与本地演示。

## Goals / Non-Goals

- 展示订单号、签收日期、已过天数、适用期限及查询结果。
- 支持明确区分本地演示与 DeepSeek 调用。
- 范围限只读查询。订单、日期和政策均为模拟数据。

## Decisions

- 使用 Python 标准库实现本地 HTTP 服务与 DeepSeek 请求，原生 HTML、CSS、JavaScript 构建页面。
- 页面由订单示例、查询区、结果依据组成。窄屏按内容顺序叠放。
- DeepSeek 只负责提出查单工具调用。应用校验工具和参数，Python 按固定演示日期与模拟店铺规则生成结论。
- 提供 7 天与 15 天的模拟店铺政策。缺少密钥时用明确的订单编号匹配驱动同一条查询链。

## Risks / Trade-offs

- [固定样本会随真实时间变化] → 页面明确显示固定演示日期，测试使用同一日期。
- [外部模型不可用] → 回报查询失败，保留可运行的本地订单示例。
