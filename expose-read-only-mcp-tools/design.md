## Context

客服工作台已能读取 PostgreSQL 订单，并按所属店铺从 Milvus 检索原文。

## Goals / Non-Goals

- MCP 客户端可发现并调用两个只读工具。
- 查询订单返回签收日期、店铺和期限。检索条款返回编号、标题、出处和原文。
- 本阶段以本机 stdio 调用为验收入口。

## Decisions

- 用官方 MCP Python SDK 处理握手、发现、调用和结构化响应。
- MCP 使用单独的依赖环境，以适配 Python 3.14 和各自的 Starlette 版本。
- 订单工具复用数据库仓储。检索工具从订单确定店铺，使用当前 Milvus 索引。
- 工具返回业务原文，客户端可决定后续如何引用。
- stdio 的标准输出用于协议，诊断走标准错误。

## Risks / Trade-offs

- [数据库暂时不可用] → 工具返回可读调用错误。
- [相同提问可能在不同店铺有不同条款] → 工具从订单确定搜索范围。
